Create a card

POST /v3/cardsidempotent · returns in 40 ms

Issues a virtual PAN on one of your BINs and returns a token. The PAN itself is held by Global Payment Network and revealed to the cardholder through the hosted view, so it never crosses your systems and your PCI scope stays where it is. Send an Idempotency-Key; a retry inside 24 hours returns the original card instead of a second one.

Body

binOne of your program BINsstring · required · DE 2, first sixrequired
cardholderName as it should printstring · 2–26 characters · DE 43 on your siderequired
form_factorvirtual or physicaldefault virtual · physical starts a fulfilment order
limits.per_txnCeiling per authorization, minor unitsinteger · inherits the program limit when absent
limits.per_dayRolling 24-hour ceiling, minor unitsinteger
metadataUp to 20 keys you want echoed backobject · strings only · returned on every authorization

Errors

400 bin_not_yoursThe BIN is not on a program this key can issue against.
409 idempotency_conflictSame key, different body inside the 24-hour window. Send a new key.
422 limit_above_programA card limit is higher than the program allows. Raise the program limit first.
429 rate_limitedSixty creates a minute in sandbox. Retry-After tells you when.
