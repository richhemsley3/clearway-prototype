Tabs or a segmented control · the rule

Tabs — different content, different data

Each panel holds something else entirely. Moving between them changes the subject, so the label carries a full-width rule and the panel below can be any shape.

Segmented control — one set of records, sliced

Same table underneath, filtered. The control is compact and sits inline because nothing about the page changes except how many rows survive.

The test: if the panel would still make sense with a different filter applied, it is a tab. If the only difference is which rows are left, it is a segmented control. A third case — a secondary facet on top of a saved view — is a chip row, not a second control.
